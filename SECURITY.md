# Reporting sensitive issues

For a report containing sensitive exploit details or accidental credentials, contact **fmuse@ambiome.ai** instead of opening a public issue. Include the affected artifact hash, protocol, trust assumption and minimal synthetic reproduction. Do not send live secrets or personal data.

This is a research demonstrator, not a production security service. No response-time commitment or bounty is offered. Public architectural counterexamples that contain no sensitive details are welcome through the issue templates.
